# wad2bsp — вставка отредактированных текстур из WAD3 в BSP-карту GoldSrc (CS 1.6 / Half-Life)

wad2bsp заменяет текстуры в уже скомпилированной BSP-карте данными из WAD3-файла — **без декомпиляции и пересборки карты**. Удобно, когда нужно обновить или «перекрасить» текстуры чужой или своей карты, а исходных файлов карт в наличии нет.

Дополняет утилиту [PackMap](https://github.com/slonenok-hacker/packmap): PackMap умеет извлекать вшитые текстуры карты в WAD (файл `*_extracted.wad`) — именно его можно редактировать (например, в Hammer / Wally) и затем вставлять обратно этой утилитой.

## Возможности

- **Замена на месте**: совпавшие по имени текстуры того же размера W x H перезаписываются прямо в BSP — miptex-данные читаются движком по смещениям, поэтому остальной файл не трогается.
- **Пересборка miptex-куска (`--rebuild`)**: если размер текстуры в WAD отличается от BSP, miptex-кусок пересобирается целиком и дописывается в конец файла. Карта немного растёт, старый кусок остаётся внутри как неиспользуемые данные — на игру это не влияет.
- **Вшивание внешних текстур**: внешние текстуры (те, что игра ищет в WAD) в режиме `--rebuild` можно заполнить данными из вашего WAD — карта станет полностью автономной.
- **Защита прозрачных текстур**: текстуры с маской прозрачности (имена с префиксом `{`) проверяются — если индекс 255 палитры в WAD не чистый синий (0, 0, 255), выводится предупреждение.
- **Исходник не изменяется**: результат всегда пишется в новый файл (по умолчанию `<имя>_mod.bsp`).
- **Самопроверка результата**: после сохранения выходной BSP перечитывается той же читалкой, чтобы убедиться, что файл корректен.
- **Два режима**: GUI и командная строка.

## Требования

- Python 3.8 или выше.
- `tkinter` (для GUI; обычно входит в поставку Python).
- Никаких внешних зависимостей — только стандартная библиотека.
